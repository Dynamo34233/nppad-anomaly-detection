[4] Severity Encoding Analysis:
  - Severity is parameterized by the scenario filename in each accident folder:
    * LOCA / LOCAC / FLB / SLBIC / SLBOC: break size % (1% - 100%)
    * SGATR / SGBTR: % of 1 full tube rupture (1% - 110%)
    * MD: % of unborated injection (1% - 100%)
    * LR: % of full load rejected (1% - 100%)
    * RW / RI: % rod withdrawal / insertion (1% - 100%)
    * LLB: % nominal letdown flow (1% - 101%)
    * Single-transient accidents (ATWS, LOF, LACP, TT, SP): full transient severity (100%)
  - Severity Binning Strategy (Tertiles):
    * Low Severity:    severity <= 33%
    * Medium Severity: 33% < severity <= 66%
    * High Severity:   severity > 66%
